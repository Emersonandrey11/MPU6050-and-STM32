How it works

Yes, a web page can show the sensor in real time, but a browser cannot talk to the ST-Link by itself. A small Python program reads the data and streams it to this page.

  1. Sensor → STM32. At 100 Hz the MPU6050 raises INT (PB12). The STM32 reads INT_STATUS and the 14 data bytes (accel, temperature, gyro) over I2C1.
  2. STM32 RAM mailbox. The firmware stores every sample, the settings, the self-test results and a register snapshot in one struct, g_telemetry.
  3. ST-Link. The debug probe can read RAM while the CPU runs. OpenOCD drives it, so no UART adapter is needed.
  4. Python. mpu6050_monitor.py reads the struct about 100 times a second, converts raw counts into g, °/s and °C, and computes roll/pitch/yaw. Commands from this page are written back into the struct.
  5. Browser. The page receives a JSON stream (Server-Sent Events) and redraws the board, the charts and the tables.
AccelerometerMeasures acceleration including gravity. Lying still, it reads 1 g straight up, and that tells you the tilt (roll and pitch). It is noisy when shaken.
GyroscopeMeasures how fast the board turns (°/s). Integrating it gives an angle that is smooth but slowly drifts. Keep the board still while it calibrates.
TemperatureThe silicon die temperature (MPU-6050: raw / 340 + 36.53, MPU-6500: raw / 333.87 + 21). It reads a few degrees above room temperature.
